# galaxian-gba-demake
Demake homebrew para Game Boy Advance hecho por un niño de 13 años con autismo y TDAH (v1.0). Tributo fan educativo y bilingüe (ES/EN) a 60 FPS hecho con Butano. Código abierto para que la comunidad cree mods y mejore los sprites. / Open-source GBA demake made by a kid 13 years with autism &amp; ADHD. Mods welcome!
